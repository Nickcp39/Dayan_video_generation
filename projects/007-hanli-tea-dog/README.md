# 韩立喝茶与撸狗：独立生成 Pipeline

**已固化控制入口与 Checker：** 参见 [直接生成接手规范](../../docs/DIRECT_ANIMATION_HANDOFF.md)；执行 `scripts/direct_animation.py`。本目录是用户接受的样片，不直接重新生成；新片用 `new --project`。当前验收绑定最终 v2 MP4，保留用户指出的卡通风格问题。两种模式总览见 [VIDEO_MODES](../../docs/VIDEO_MODES.md)。

状态：两个动作镜头已在本地 RTX 4090 生成，10 秒成片见 `review.html`。此目录独立于已有角色替换流水线，本项目未改动旧生成脚本、配置、声音权重和成片。视频无真人/原片动作输入；人物参考来自已有韩立静态图。

## 本次实测结果

- 图片准备：本地 FLUX.2 Klein 4B FP8，角色正面、三分之四角度、侧面设定；狗参考、茶亭构图、喝茶与抚摸首帧分别审查。多视图用于角色设定与检查；实际场景用清晰人物原图和狗参考，视频用选定单帧。
- 动画：Wan2.2 TI2V-5B FP16，960×544，24fps，24 步，每镜头 121 帧，再各取 5 秒合成。喝茶镜头可见杯子抬至嘴边再放低；抚摸镜头可见手从额头移动到耳侧。没有使用动作源视频。
- 引擎实际执行：喝茶 250.879 秒（含首次视频模型加载），抚摸 117.051 秒；两段合计约 6 分 8 秒。抚摸另排队 141.659 秒；不能把客户端约 260 秒全部算成生成时间。下载、图片迭代、配音、审查和合成另计。
- 声音：已有第八轮 GPT-SoVITS，本地合成 4.7 秒原速台词，ASR 覆盖全部指定文字。按中间静音切成两句排入 10 秒时间轴，没有变速或变调。
- 前期返工：淘汰三只手/两只杯子的分镜；修复后才生成视频。第二镜头补杯曾误删茶壶，最终用本项目生成的杯子素材做静态道具合成，保留茶壶与已通过的人物、狗。这一步不是视频换皮。
- 限制：角色是依据韩立参考生成的再创作外观，并非完全还原原作脸型；抚摸幅度较小，未准确完成提示词中的两次完整往返。第 5 秒采用切镜，没有展示放杯全过程。台词按内心独白处理，未做音素口型；没有添加环境音和配乐。只验证这一条能跑通，尚未证明批量稳定。

审片页同时展示成片、两个原始镜头、失败和修正的分镜；模型来源、API 工作流、种子、计时及审查保存在各阶段目录和 `evidence/`。

## 公开流程依据与本地对应

1. [Runway 参考图教程](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)：人物和场景分别迭代，检查一致性，再组合镜头。本项目采用本地 FLUX.2 Klein 的参考图编辑，而非调用 Runway。
2. [ComfyUI FLUX.2 Klein 教程](https://docs.comfy.org/tutorials/flux/flux-2-klein)：4B 蒸馏版支持单图、多图参考编辑。用于人物角度、场景和镜头起始画面；不把多面拼图直接当视频首帧。
3. [ComfyUI Wan2.2 原生教程](https://docs.comfy.org/tutorials/video/wan/wan2_2)：起始图片输入 Wan22ImageToVideoLatent，结合动作提示生成视频。本项目复用已有 TI2V-5B，非 Animate 换皮。
4. [创作者动画制作复盘](https://www.reddit.com/r/StableDiffusion/comments/1to7uzx/i_built_a_full_ai_animation_pipeline_and_made_a/)：人物角度、背景和道具先修整，再生成视频；作者用的显卡和音频服务不作为本项目性能或免费证据。

以上是复用公开制作方法，不声称复制某大厂内部生产系统，也不在一次成功后声称流水线已经稳定。

## 制作约束

- 时长：10 秒；两个约 5 秒镜头；原生横屏动画，第一轮 960×544 / 24fps，必要时另存降档测试。
- 风格：已有参考图的中国仙侠 3D 动漫外观。成年韩立，黑色长发，青蓝长袍、金银肩饰；同一只浅黄白色短毛中华田园犬，困倦但无受伤表现。
- 场景：安静的木制茶亭，暖日光，青瓷杯、木茶桌，竹林背景。
- 镜头一：韩立端杯小饮一口，放低杯子，轻皱眉察觉异味。狗在旁休息。
- 镜头二：同一场景，狗伏在靠近韩立的木桌上；韩立低头，用空闲手轻抚狗头。原定长凳，经分镜审查接受桌面构图，并在两镜头保持一致。
- 原文台词：今天的茶水有股怪味啊，狗狗怎么也没精打采的。
- 声音：读取已验收的第八轮 GPT-SoVITS 配置，不重新训练。以自然语速合成，按句排时间轴；不承诺音素级口型。

## 阶段与证据

角色角度和资产检查 → 场景与分镜图检查 → 图生视频 → 动作/身份抽查并保留重试 → SoVITS → 字幕/剪辑 → 全片解码、时长核验、审片。

所有 API 图、提示词、随机种子、依赖来源、历史输出和耗时另存。每个阶段可复跑、已有结果不盲目覆盖，失败与成片均保留。
