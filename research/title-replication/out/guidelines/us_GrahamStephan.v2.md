## 1. 一句话定位
观众是想变富的美国普通人和年轻投资新手，关心房产、指数基金、信用卡、创业副业和美联储新闻。他们来这里，是想听一位白手起家的百万富翁用自己的钱和经历，把"钱的事"讲成能马上照做的方法，或者对热点给一个有分寸的判断。这个判断可以是"别慌"，也可以是"这次真要小心"。

## 2. 从选题到中心思想
论点类型分布：advise 约 60%，judge、predict 次之，narrate、expose、explain 较少。作者本人的经历是论据，结论却要写成观众也能照做的通用法则。

**公式 A：亲身经历 → 可复制的特质或优先级清单（advise）**
写法是"我做过 X → 你可以照做的 N 条"。条目要具体、可列举，例如列出几种特质、几个步骤，不要只写"坚持、专注"这类泛词。

**公式 B：热点新闻 → 数据判断 → 具体防守动作（predict / advise）**
先用数据判断风险到底有多大，再看情况落点：
- 风险被夸大：别恐慌，照常定投。
- 风险真实存在，比如信贷收紧、房价还会跌、利率高位维持更久：直接承认它，再给具体动作，例如留现金、买短期国债、低价试探出价、分散投资。

不要默认把所有危机都写成"被夸大"。政策类选题要点名"真正有效的解法"，比如增加供给、调整税制，不能只说"不会通过"。

**公式 C：以内行身份评测产品 → "合格但不是最优"（judge）**

**公式 D：拆解一个数字或心态，或者算一笔对比账（explain）**
例如租和买、几种方案对比，结论要说明在什么条件下谁更划算。

**公式 E：记录别人或别人的生意（narrate → advise）**
跟拍创业者、名人一天，总结出成本、收入，以及普通人能照搬的几条习惯。

## 3. 标题公式
1. **How To + 结果 + 具体金额或比例**：方法类首选。素材虽然是"我的经历"，标题也常改写成面向所有人的结果，比如"超过多数人""提前退休"，不必写成 How I。
2. **第一人称或动名词事件**：选题是作者本人的决定时，用 Why I / My；作者去体验、跟拍时，优先用动名词开头（Spending / Making / Buying + 时长或金额 + 对象），少用 I Spent。
3. **新闻快讯**：近期常用写法是"BREAKING: + 机构 + 动作（可加 !）+ (固定说明)"。括号里的说明从 Major Changes Explained、Do This Now 这类短语里选。旧的"全大写整句 + *AGAIN* + 竖线"写法仍可参考，但**不要照搬任何旧标题原句**，每期都要换成本期的具体动作，比如宣布降息、暂停、意外加息。
4. **全大写断言 + 括号利益点**：政策或产品利好用。例如"$X 某事物 ARE BACK (Get Paid To …)"。
5. **The TRUTH / REAL Cost about + 主体**：评测、揭秘时用。
6. **警告或夸张现状**：宏观、房市题材用。句式有"A Warning For The + 年份 + 市场"、"The + 市场 + Is Getting + 强烈动词"、"Americans Are + 动作 + Like …"。
7. **对比提问**："A vs B: Which Is ACTUALLY + 形容词?"。这是少数该用问号的场景。
8. **系列标签**：跟拍创业者赚钱的选题，在竖线后面挂固定系列名 | Undercover Millionaire。

## 4. 标题与中心思想的关系
大约四成"只说一半"，三成"夸大"，少量只给话题或提问，直接给结论的极少。
- **宏观或房市题材，标题要比结论更吓人**。即使结论是"不会崩"，标题也写"正在被摧毁"或"警告"，不要把结论"不会崩"直接放进标题。
- 个人经历、评测题材：抛出"真相、后悔、怎么做到"，答案留在视频里。
- 对比计算题材：用提问把悬念交给观众。

## 5. 硬指标
- 长度 5–12 词，中位数 8 词。
- 问号整体很少（约 4%），只在 vs 对比时用。感叹号偶尔出现在 BREAKING 新闻里。
- 数字约 45%，以金额为主（$0、$500、$400,000），其次是百分比（99%）、时长（24 Hours）、年份。
- 全大写：强调 1–2 个关键词（TRUTH、ACTUALLY、REAL、BROKE）；整句大写只用于新闻断言。
- 后缀：**近期以圆括号为主**，例如 (Do This Now)、(Major Changes Explained)、(Get Paid To …)。竖线主要留给系列标签和少量 The Full Story，不要每个标题都加竖线。
- 前缀：新闻可用"BREAKING:"。
- 不用方括号。结尾偶尔用".."制造未完感。
- 人称：第一人称约 33%，you 约 28%，另有不少无人称的现状描述（Americans / The Housing Market）。

## 6. 这个作者从不做的事
- 不用方括号标签。
- 不骂人、不讽刺。
- 不推荐投机暴富，结论回到长期、分散、低费率、量力而行。
- 不脱离个人账本或实地经历空谈。
- 不在标题里直接说出安抚性的结论，比如"不会崩""别担心"。安抚只放在视频里。
- 不机械套用同一个新闻标题模板。

## 7. 写新一期的步骤
1. 判断类型：方法类、热点新闻、政策、产品评测、对比计算、个人事件、跟拍他人。
2. 找出作者能接上的地方，但想好标题面向"你/所有人"还是"我"。经历类优先考虑通用结果。
3. 立论：先判断风险是真的还是被夸大，再给出 2–3 个具体动作或具体解法，不要只写"长期投资"。
4. 挑出最醒目的数字，金额优先，其次是百分比和时长。
5. 按第 3 节套公式：新闻用 BREAKING + 括号；跟拍用动名词 + 系列标签；对比用 vs 提问；房市宏观用警告或夸张现状。
6. 定关系：宏观题材把标题写得比结论更强烈；个人和评测题材只说一半。
7. 检查硬指标：5–12 词；后缀优先用圆括号；大写 1–2 个词；没有照搬任何旧标题原句。
8. 念一遍，确认标题像一条有具体数字、有悬念的"钱的消息"，而且没有提前说出答案。
