## 1. 一句话定位
这个频道面向担心行情的日本个人投资者，他们关注日元汇率、美股、日股、美债、商品和加密资产。前华尔街对冲基金从业者高橋ダン在重大数据或央行事件前后给出判断：会不会暴跌、现在该买什么、他自己怎么操作。另有少量交易规则、致富方法类的教学内容，年初和年末会出「总结 / N 个预测」类节目。

## 2. 从选题到中心思想
论点只有两种类型：advise（给操作建议）约占 53%，predict（判断走势）约占 47%。中心思想要落到具体方向和具体资产上，而且通常分两层：**短期判断＋长期判断，两层方向常常相反**。例如短期有回调风险，但长期主题没有结束；短期要谨慎，长期分批积累。只写一层，或者把两层写成同一个方向，都会偏离作者的意思。

**公式①：事件 → 拆出真正的变量 → 方向和配置**
先说明市场看错了地方，再指出真正该看的变量，最后推出结论。这个变量必须来自素材，而且要沿着它推导下去，比如「生产率强 → 降息预期落空 → 某个时点下跌」。不要只把这个变量提一下，然后跳到泛泛的长期配置。
**公式②：极端数据 / 历史类比 → 罕见机会**
从素材里取一个最关键的极值就够了，不要额外堆砌「N 年最高 / 最低」。
**公式③：反驳大众恐慌（逆向）**
先摆出恐慌叙事，再用定义、比率或持仓数据拆穿它，常见落点是「会跌，但不是现在」或「不必对冲」。
**公式④：亲身经验 / 年度节点 → 数字清单**
「N つのルール」「N つ予測」「注目はこの N つ」。

中心思想里要写清**时点**（数据发布日、几月、哪一年前后）和**配置顺序**（先买什么，其次买什么）。

## 3. 标题公式
1. **「主体、结论 / 警告」两段式**：前半写资产或事件，后半写判断。
2. **问句收尾**：二元悬念放在句末，写成「〜か？」「〜のか？」。主语通常是一个主题词（如泡沫、底部、暴跌），**不一定要点名具体公司或数据名称**。
3. **指示词悬念**：用带引号的「これ」「ここ」「この時」「この N つ」代替关键答案，比如「X は「これ」がキッカケ？」「次の X は「この時」に起きる？」。这是后期最常用的 teases 手法。
4. **【数据型标签】+ 判断**：括号里不只放【速報】【緊急】，也放极值本身，比如【N年ぶりの急落】，括号外再写意义（「〜の始まり」）。【速報】只在突发政策、突发消息时用，不要每期都加。
5. **第一人称**：「僕の投資戦略？」「僕の N つ予測」。适合对立事件（A vs B）和年末年初展望。
6. **长总结式**（年初 / 年度回顾）：先用一个问句给出钩子，后面跟上「X、Y、Z のまとめ」。
7. 早期的双语格式已经停用。

## 4. 标题与中心思想的关系
teases 约占 40%，asks 约占 27%，states 约占 17%，labels 约占 13%，amplifies 约占 3%。
- **teases**：标题只写现象或主题，把具体资产留到视频里讲。标题里不出现数据名称（如 CPI、雇用統計）或个股名，往往比点名写更像作者本人。
- **asks**：问题是二元的，视频里给出明确答案，而且答案常常反转（「会崩，但不是现在」「短期回调，长期不会破」）。
- **states**：只有在有具体价位或时点时才用。
- **amplifies**：只在反驳恐慌叙事时用。

## 5. 硬指标
- 长度：中位数 16 字，p10–p90 为 10–44 字。日常标题大多 10–18 字，只有总结式会超过 30 字。仿写不要比这个更长，也不要更夸张。
- 问号：全部标题中占 26%，爆款中占 37%。后期常用「？」，「❓」用得较少。
- 数字：全部标题中占 39%。只写素材里最核心的一个数字，可以是价位、跌幅、年数或清单数。
- 括号标签：占 26%，有【速報】【緊急】【N年ぶりの〜】和教学类标签。
- 人称：third 43%，none 31%，first_person 13%，you 13%。
- 情绪：alarmed 34%，urgent 19%，curious 17%。
- 方向词要和金融含义一致：收益率上升等于债券价格下跌，不要写反。

## 6. 这个作者从不做的事
- 不用竖线「|」。
- 不用愤怒、讽刺或搞笑的语气，几乎不用「我们」视角。
- 不写纯中性的新闻复述。
- 中心思想不会停在「不确定」。
- **不会连续几期用同一个标题句式**。第 3 节的例子只是句式示范，**不要照搬原句**，也不要换个数字就当成新标题（如「N年ぶり、ココを買う時です」）。同一套句式在一批里最多用一次。

## 7. 写新一期的步骤
1. 从素材里找出触发事件、涉及的资产，以及作者给出的那个关键变量。
2. 定论点类型。写出短期和长期两层，确认两层方向是否相反，再补上时点和配置顺序。
3. 只保留素材里最关键的一个极值，不要另造数据。
4. 选定标题与论点的关系：建议类、突发类默认用 teases；二元悬念用 asks；有价位才用 states。
5. 选句式时，优先考虑指示词悬念（「これ / ここ / この時」）、句末问句、【数据标签】或「僕の〜」，再考虑两段式。不要默认写成「事件名 + 結論」。
6. 检查：10–18 字左右；最多一个危机词或悬念词；【速報】只给真正的突发事件；没有和旧标题或本批其他标题重复的句式；方向词没有写反；不用竖线。
