## 先看结论

1. **最值钱的不是预测，是"预测对了也会做错"的复盘。** 金融文的主线从 2025 年的"BTC 是数字黄金、价格是纯数学"，走到 2026 年的"预测对了没撑住""懂产品不等于懂股票""底层逻辑要能被推翻"。这条从"预测市场"到"管住自己"的弧线是别人没有的素材，也正好接上前次市场调研定的"知道却做不到"栏目。
2. **素材集中在 BTC，而国内平台对 BTC 最敏感。** 有正文的 9 篇金融文里，7 篇以 BTC 为主线。2026-02 八部门新规重申虚拟货币相关业务属非法金融活动，抖音财经公约也有专门禁令。国内平台上，BTC 只能当故事背景；价格预测和买卖区间不能上。
3. **能直接改成 30–60 秒短视频的有 7 条（A 档），稍加处理还有 5 条（B 档）**，大部分来自 4/19、5/1、6/20、3/15 四篇。三篇预测和宏观长文不适合做国内短视频。
4. **巴芒理念本身没有系统写过。** 《价值投资的四条核心心法》在网站和 GitHub 上都是空文件，其他文章里巴芒和段永平只作为引语出现。如果节目是"一条讲一个巴芒理念"，博客撑不起来，需要另建理念库。
5. **标题没有固定招牌。** 你的标题长度、口语度和小Lin说接近，但没有固定栏目标签或招牌句式。上一份标题研究的结论恰恰是：每个百万级频道都有这样一个招牌。

## 2. 逐篇拆解

字段沿用 `title-replication` 内容拆解的口径：中心论点、论点类型（explain / predict / advise / judge / narrate）、标题和论点的关系（states 直接说结论 / asks 提问 / teases 只说一半 / labels 只是话题名）。

- 论点：BTC 是对冲法币贬值的数字黄金，本轮约 2025 年 9 月见顶于 13–15 万美元，2027–28 年回落到 4–5 万美元筑底。
- 切入：拿黄金在宽松周期里的走势类比 BTC。
- 注意：标题说"内在价值"，正文其实是价格预测，题文不符。全文 358 字，像提纲。

**2025-05-31《为什么比特币四年一轮回，但你依然赚不到钱？》** · explain · asks

- 可用：①②两节（扛不住波动、"你以为在投资，其实在追星"）。
- 注意：第③节"国家不希望你变富，这是设计好的"不能用于国内平台。"财经博主多数……贩卖情绪"这句会被拿来对照你将来的身份，但可以反过来变成人设承诺："不荐股、不喊单"。

**2025-12-30《……2026年国债市场"漏水"的可能路径》** · predict + explain · labels
- 论点：传导链是 BTC 周期回调 → 稳定币缩表 → 美债少了一个边际买家；再叠加日本加息、外资退场、高额发债和选举年政策混乱，2026 年年中国债市场某个薄弱环节可能"漏水"，之后美国走向隐形 YCC 加财政主导。
- 结构：2025 年资产表现 → BTC 四年周期 → 稳定币和美债 → 10y-2y 与 1983 年类比 → 日本和外资 → 特朗普选举压力 → 漏水时间线 → 对美股企业的影响。
- 可用：博客里最硬的宏观框架，可以拆成不带价格的"一个机制"讲解，比如稳定币为什么会持有美债、利差倒挂后转正是什么意思。更适合长视频或 YouTube。

**2026-04-19《我预测对了 2026 年的腰斩，可我自己没撑住》** · narrate → advise · teases
- 论点：预测对了不等于赚到钱。第一次遇到"清仓之后怎么办"这道题，做不对是正常的，要用制度替代意志力。
- 可用：**全博客最强的短视频素材。** 反差强（预测对、减仓也对，最后一笔在马桶上手滑清仓，不到一天又全部买回）；细节具体；结论能直接照做（减仓资金先进独立账户、设 72 小时冷静期；仓位分成"永远不动"和"可调"两块）；还有巴菲特 Waumbec 的类比："错误是决策框架里的一个零件"。
- 注意：文中写 Waumbec 收购于 1978 年，伯克希尔信件记载为 1975 年。"每次决策前都会问自己是不是又一个 Waumbec"需要出处。"预测基本兑现"是自述，而且 12 月预测里的"稳定币暴雷"这篇没有提到是否发生。

**2026-05-01《看不懂的公司不投》** · judge · states
- 论点：懂产品不等于懂股票。看不懂的东西一直涨时还能不投，才是能力圈；仓位管理也是心态管理。
- 可用："我知道显卡会涨价，却没拿住 NVDA"是很好的开头（前次调研也选了它）。"不是每一种钱都属于我"可以当结尾金句。核心仓 / 观察仓的分法可以照做。
- 注意：SanDisk、Nebius、NVDA 是真实个股，只能作为经历提，不能像推荐。"巴菲特大概率不会买"是推想，文中已经标明，视频里也要标。

**2026-09-04《BTC、黄金与道德资产》** · judge · asks
- 论点：短期行情由美债变化推动，可能横盘 3–4 个月；长期持有要看能被事实推翻的底层逻辑。人和生意里值得长期持有的是信誉，"道德资产"不应折现。
- 可用：写法最成熟的一篇。给出可检验的预测，公开更新旧判断而不改写记录，附了参考资料，并且把价值评价和事实指控分开。"底层逻辑也必须能被事实推翻，否则就成了信仰"可以单独成一集。
- 注意：点名孙宇晨。文中已经很克制，但视频里批评真实人物的风险高，应去名。

**2026-06-20《做生意，诚信不是道德题，是算术题》**（生意）· advise + narrate · states（反常识重构）
- 论点：诚信是长期算术题：讲诚信的人亏几个季度的销量，不讲的人亏掉整个牌子。有些生意算总账不如不接。
- 可用：两个客户故事都是现成的 30–60 秒结构。一个客户看了十年朋友圈才下几百万的单；另一个拿竞品价压价、骂得最凶，后来成了回头客。段永平"对手虚标 800 线、步步高不跟"的故事也能用。
- 注意："妓女滑坡陷阱"这个类比不能上视频。"灰色环节分包出去"一段读起来像规避责任的商业建议，前次调研也标过。段永平采访需要找原始出处。

**2026-03-15《创业十年》**（生意）· advise · labels
- 论点：创业的启动条件不是技术牛或融到大钱，而是找对核心股东、慎拿资本、看清自己的生态位、保持现金流健康。
- 可用："账上永远留够不开张三年也能活的钱""拿了大钱，等于把节奏、压力和话语权一起卖掉一部分""肯德基和麦当劳中间卖小笼包"。这些和巴芒的安全边际、护城河一脉相承，但都是你自己的话。

## 5. 写法特征

- **口吻**：第一人称、口语、短句，敢自嘲（马桶、手指一滑、"理性得一塌糊涂"）。最强的段落都有一个具体的物件或数字：十年朋友圈、72 小时、150%、800 线。
- **常用结构**：现象 → 我的经历 → 巴芒或段永平的一句话 → 反思 → 金句收尾。"赚钱很难，守住更难"用过两次（7/14、4/19）。这个结构稍微压缩就是"困境 → 小例子 → 理念 → 落点"的短视频骨架。
- **2026 年明显更克制**：加了风险提示，区分推想和事实，附参考资料，主动标明"这是价值评价，不是指控"。2025 年的文章更绝对。
- **标题**：中文标题大多 16–23 字，和小Lin说的平均 23 字接近；宏观长文 41 字，像论文题。

| 你的标题 | 对应的大V手法（见 [finance-titles 报告](../finance-titles/REPORT.md)） |
|---|---|
| 我预测对了 2026 年的腰斩，可我自己没撑住 | 美国式第一人称反转：我做了 X，结果意外 |
| 为什么比特币四年一轮回，但你依然赚不到钱？ | 小Lin式口语提问 |
| 做生意，诚信不是道德题，是算术题 | 反常识重构 |
| 看不懂的公司不投：从 SanDisk、Nebius 到 NVDA 的复盘 | 结论加案例 |
| BTC周期回调、稳定币收缩与10y-2y利差：…… | 话题名式，信息全在标题里，没有悬念 |
