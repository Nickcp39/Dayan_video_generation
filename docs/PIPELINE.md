# 两种模式的 Workflow

## 直接生成：这次喝茶撸狗的流程

```mermaid
flowchart TD
  A[剧本：喝茶、摸狗、两句台词] --> B[人物与狗参考、角色角度设定]
  B --> C[Klein 生成与修整两张分镜首帧]
  C --> Q{审查手、服装、道具和构图}
  Q -->|返工| C
  Q -->|通过| W[Wan2.2 TI2V-5B：两段约5秒动画]
  W --> R{动作和画面检查}
  R -->|保留失败版后重试| W
  A --> V[已有第八轮 SoVITS：生成台词]
  V --> T[原速时长检查、逐字试听]
  R -->|选定镜头| F[两个镜头各取5秒、安排配音和字幕]
  T --> F
  F --> K[Checker：媒体、帧数、声音时间轴和镜头来源]
  K --> U[用户看片、验收、冻结配置与产物]
```

多面图用于角色设定与检查，Wan 接收的是镜头首帧。前期图像决定构图、道具和很大一部分画风；Wan 负责从首帧生成运动。声音是独立支线，当前不提供音素级口型。两条支线表示数据关系，不表示同时占用 GPU。

## 换皮：保留原片动作与背景

```mermaid
flowchart TD
  A[原视频：选择连续镜头] --> B[裁切与尺寸归一化]
  B --> M[SAM2：目标人物蒙版]
  B --> P[DWPose：身体和面部动作]
  H[韩立形象参考] --> W[Wan2.2 Animate 角色替换]
  M --> W
  P --> W
  W --> C[蒙版外恢复原片背景]
  T[台词＋第八轮 SoVITS] --> F[原速配音与成片合成]
  C --> F
  F --> K[Checker＋人工审片＋用户验收]
```

## 检查如何分工

- 自动 Checker：配置与模型哈希、输入和实际执行图、执行结果、视频时长/帧数/解码、音频时间轴和验收绑定。
- 看图看片与试听：像不像韩立、手是否自然、动作是否正确、声音有没有漏字、表现是否满意。
- 失败保留现场；已知任务 ID 只恢复等待/下载，提交状态不明时不自动重复提交。

执行细节见 [模式总览](VIDEO_MODES.md) 和两份接手规范。旧的四阶段 FaceFusion 规划已经退出当前执行路线。
