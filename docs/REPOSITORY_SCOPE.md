# 仓库范围与本地依赖

Git 保存两种已验证流程的代码、Checker、ComfyUI API 图、配置示例、提示词、模型清单、参数锁和制作文档。旧的 FaceFusion 四阶段规划、卖瓜脚手架和泛用下载/合成入口已从当前仓库入口移除；早期版本仍在 Git 历史中，本机副本保留。

## 不上传的内容

- Wan、FLUX、Qwen、SoVITS 等模型权重及第三方整合包、Python 虚拟环境。
- 人物图片、参考音频、源视频、生成视频、训练切片和网络下载缓存。
- 本地审片页、失败中间产物、逐轮执行日志、临时对比实验和完整 `releases/` 保存快照。
- 与这两种模式无关的下载器、打包程序和其他未验收试验。

这些文件保留在本机，`.gitignore` 只使其退出版本管理。基础模型的来源和 SHA256 仍保留在清单/锁里。原换皮脚本和两种模式的锁不为本次整理而更改。

## 拉取仓库后能做什么

可以阅读制作流程、参数与失败处理，查看/改进控制代码，准备新项目配置。**仅 clone 不能立刻生成或完整复查历史样片**：需要恢复本地模型、已接受的图像/声音资产、推理环境，以及要复查的样片产物。

当前锁记录的是 Windows/4090 实测机器的文件哈希和部分绝对路径，不是跨机器安装包。迁移须按接手规范建立新环境并复验；不能通过重写旧锁掩盖差异。

两种模式完整 Checker 与媒体回归测试需本地资产。无需模型的仓库检查是：

```powershell
python scripts/check_repository.py
```

检查 Git 索引中的文件类型、大小、Python/JSON 语法，以及已锁仓库代码的字节是否一致。本次提供本地轻量检查入口，不包含远端 GPU 生成验证。

为避免 Windows 自动换行改变锁定文件 SHA256，`.gitattributes` 保存文件原始字节。新配置和源代码应使用 UTF-8；不要在维护期间批量转换现有已锁文件的换行。
